## Запуск за минуту

Нужен Node.js 20 или новее. В терминале из этой папки:

```sh
node server.cjs
```

Откройте **http://127.0.0.1:4174/**. Установка зависимостей и сборка не нужны.
Альтернатива: `npm start`. Остановить сервер: `Ctrl+C`.

Не открывайте `dist/index.html` через `file://`: приложение использует ES-модули и загрузку ассетов через HTTP. Физический микрофон требует HTTPS или localhost и разрешение браузера.

## Что показать

Подготовка длится **4 секунды**, кольца повторяют двухсекундную анимацию. Затем включите свой микрофон или нажмите **«Демо голоса»** в настройках. Можно отключать микрофон, переключать демокамеры, завершить звонок и повторить сценарий.

В панели есть девять сцен Figma, отдельные состояния собеседника, цвета, настройки света и шесть режимов демо. Для проверки эффекта физический микрофон не обязателен.

## Проверка

```sh
npm test
```

Команда сверяет исходные файлы с зафиксированной копией и запускает проверки модели звука. Можно без npm:

```sh
node scripts/verify-snapshot.mjs
node scripts/check-syntax.mjs
node tests/audio-check.mjs
```

## Состав

`dist/` — готовый сайт, `tests/` — исходные проверки звука, `server.cjs` — локальный сервер. Новые `scripts/` и документация служат только для передачи. Сайт не использует их во время работы.

`ENGINE-NOTES.md`, `UI-REFINEMENTS.md`, `QA.md`, `APPROVED-HANDOFF.md` и `docs/ORIGINAL-README.md` сохранены из исходного проекта как история решений. Некоторые записи описывают ранние этапы и старые локальные пути; актуальная точка входа — этот README и DEVELOPER-GUIDE.

Это визуальный прототип: удалённый участник, камеры и динамик представлены демосостояниями. Реальный микрофон анализируется локально, без записи и отправки аудио. Подключение WebRTC и серверной части описано как следующий этап в гайде.

Экспорт не содержит исходную Git-историю, Sites hosting manifest или данные авторизации. Для разработки используйте отдельную копию и отдельный хостинг; текущая одобренная ссылка остаётся эталоном.
