# Звонок · живой свет

Новый отдельный прототип на HTML/CSS/JavaScript, без сборки и внешних runtime-зависимостей.

Site project_id: appgprj_6acea96c50888191804114b76934c75a. Новый URL: https://call-glow-prototype.alexmanga635.chatgpt.site/. Новый Site создаётся приватным; доступ не расширялся.

Старый фон остаётся по https://light-motion-lab.alexmanga635.chatgpt.site/?v=6f82df0; его Site, исходники и backup ZIP не изменялись.

## Запуск

Нужен Node.js. Из этой папки: node server.cjs. Открыть http://127.0.0.1:4174/. Микрофон работает в secure context: localhost или HTTPS.

## Сценарий

Через4 секунды подготовка сменяется соединением. Три оригинальных кольца плавно подсвечиваются по очереди, слегка поднимаются и дышат; двухсекундный цикл повторяется до подключения. Нажать круг микрофона и разрешить звук или «Демо голоса». При начале обычного сценария демоучастник подключает микрофон. Свои кнопки управляют собственным микрофоном и демовидео. В панели у собеседника независимые переключатели микрофона и камеры. При двух камерах первое действие переворачивает демопревью. Нажатие на видео скрывает/возвращает управление. «Завершить» освобождает микрофон и фиксирует таймер; «Повторить» запускает сценарий заново.

«Настройки» содержит девять сцен Figma, четыре редактируемые палитры, эффекты света, независимые реакции лучей/градиента, паузу и сброс. Палитры сохраняются отдельно в течение открытой сессии. Режимы демо: тихая/обычная/громкая речь, тишина, тихий шум, короткие щелчки. Демо использует ту же microphoneTarget и сглаживание, что физический микрофон. Это визуальный прототип, без настоящего удалённого звонка и без захвата камеры.

## Проверка

node tests/audio-check.mjs. QA.md содержит результаты и границы проверки физического микрофона. WebMCP configure_call_prototype позволяет переключать сцены и тестировать эффекты без захвата звука. window.callPrototype.snapshot() предоставляет read-only снимок состояния для диагностики.

К публикации относится только новый .openai/hosting.json. Не заменять в нём project_id на ID бэкапа.
