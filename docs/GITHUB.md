# Новый приватный репозиторий

Передавать нужно всю папку пакета, включая `dist/assets`, шрифты, гайд и проверки. Имя для нового репозитория: `call-glow-prototype-handoff`. Видимость — **Private**.

`private:true` в package.json запрещает случайную публикацию npm-пакета; приватность GitHub задаётся отдельно при создании репозитория.

Если используется GitHub CLI, сначала авторизуйтесь штатно через `gh auth login`, затем из корня пакета:

```sh
git init -b main
git add .
git commit -m "Export approved call prototype v5 and developer guide"
gh repo create call-glow-prototype-handoff --private --source=. --remote=origin --push
```

Если локальная Git-история уже создана, пропустите первые три команды. Перед отправкой проверьте `git remote -v`: origin должен указывать на новый репозиторий вашего GitHub-аккаунта.

Дайте разработчику доступ через настройки этого приватного репозитория. README содержит запуск, DEVELOPER-GUIDE — детали переноса, SOURCE-MANIFEST — контроль исходной версии. Для дальнейшей разработки используйте отдельную ветку. Проверка снимка намеренно обнаружит изменения эталонных файлов; это ожидаемо в продуктовой ветке.

## Отдельное размещение

Размещается содержимое `dist/` как статический сайт по HTTPS, без сборки. Сохраняйте структуру ассетов. Node-сервер нужен только для локального просмотра.

В экспорт не включён `.openai/hosting.json`. Если используется Sites, создайте новый проект и новую привязку. IDs в PROTOTYPE-SNAPSHOT.json нужны только для происхождения снимка. Одобренный адрес звонка и отдельный бэкап фона не перенастраивать.
