# Гайд для разработки: одобренный звонок v5

## 1. Точка отсчёта

Заказчик одобрил внешний вид, настройки и весь сценарий текущего [прототипа](https://call-glow-prototype.alexmanga635.chatgpt.site/). Этот пакет фиксирует версию 5, commit `fcdf9f841d6bb6b404d2e4d6054f7cae9f09ab26`. Задача передачи — воспроизвести это поведение в продукте, сохранив эталонную ссылку.

Сначала запустите `node server.cjs`, посмотрите флоу и режимы демо. Затем выполните `npm test`. Все исходные файлы перечислены в SOURCE-MANIFEST.json; новые документы и утилиты не меняют приложение.

## 3. Состояния и флоу

`call` в app.js хранит `stage`, `localMic`, `peerMic`, `localCamera`, `peerCamera`, `fullVideo`, `speaker`, `flipped`, `fixture`, `palette`, `demoLevel`. Собственный микрофон и микрофон собеседника независимы.

Обычный сценарий:

1. `restart()` освобождает аудио, сбрасывает таймер и состояние, показывает подготовку.
2. Через **4000 мс** `connected()` переводит в `stage='call'`. Оба микрофона пока выключены; появляется сообщение о микрофоне собеседника.
3. Своя кнопка микрофона запрашивает настоящий звук. При успешном доступе `joinPeer()` через 800 мс включает демомикрофон собеседника. «Демо голоса» включает свои голосовые эффекты без разрешения и сразу активирует демоучастника в обычном флоу.
4. Кнопки камеры показывают оригинальные демофото. Нажатие на видео собеседника скрывает или возвращает управление. Кнопка динамика при своей камере зеркалит демопревью.
5. `endCall()` останавливает звук и таймер, показывает завершение. «Повторить» снова запускает четырёхсекундную подготовку.

Пресеты в панели — управляемые кадры для сравнения с Figma. `preset()` останавливает аудио и выставляет `fixture=true`: значок включённого микрофона в пресете **сам по себе не означает захват реального звука**. Таймер там 00:51; для реального времени используйте `scene:'flow'`.

| Сцена | Figma node | Особенность |
| --- | --- | --- |
| `preparing` | 3522:1719 | Лавандовый фон, циклические три кольца |
| `connected` | 3522:1757 | Серый фон, микрофон собеседника выключен |
| `active` | 3522:1792 | Золотой фон, активный микрофон с Glow |
| `muted` | 3560:5502 | Собственный микрофон выключен, золотой фон и подсказка |
| `own-video` | 3522:1833 | Собственное небольшое демопревью |
| `both-video` | 3530:3018 | Видео собеседника и своё превью |
| `peer-video` | 3534:3225 | Только видео собеседника |
| `full-video` | 3534:3145 | Видео со скрытым управлением |
| `ended` | 3694:4930 | Тёмный фон, розовый таймер, уведомление с иконкой завершения |

В `auto` фон лавандовый при подготовке, тёмный при завершении, серый при видео собеседника или его выключенном микрофоне, иначе золотой. Выключение **своего** микрофона при активном собеседнике сохраняет золото. Переход палитры длится 650 мс. Пользовательский выбор палитры переопределяет фон, кроме завершения.

## 4. Сохранённая композиция света

[Источник Figma](https://www.figma.com/design/p7896b2XIPGOtu6JO7G3h6/App---Design-Concept?node-id=3534-3308), секция 3534:3308, базовый экран **402×874**. Оригиналы уже включены; повторный экспорт для запуска не нужен.

- `light-texture-2.png` — оригинальная фотография лучей 1024×1024, Figma image hash `2a3fd1d45b1a12fd3e6d8913cfd5618b0d307408`. Color dodge, прозрачность 0.32, exposure −0.07. Исходный слой вертикально перевёрнут; это учитывает renderer.
- `light-mask-2.svg` — исходная растушёванная маска 582×868, включая 24 px полей вокруг формы 534×820.
- Подложка `#f4f4f4`. Группа на x=−90, y=64; золотая композиция y=67. При иной высоте экрана группа привязана к нижней части. **Голос не изменяет положение или форму маски.**
- Текстура в координатах группы: x=−170, y=83.854, размер 816×682.336. Цветной слой: x=66, y=71.336, размер 448×536.905, blur 94 CSS px.
- Слои света 02–10 и исходная зернистость 09 сохранены. Подробности интерпретации blend modes — в ENGINE-NOTES.md. Не заменяйте их скриншотами или заново нарисованными лучами.

WebGL изменяет UV исходной фотографии: плавное смещение, масштаб, лёгкое расхождение и волна при голосе. Градиент отдельно деформирует цветовые области; одинаковые цвета продолжают двигаться через светлоту. Color dodge и локальное молочное высветление сохраняют детали света. Голосовые флаги действуют отдельно на лучи и градиент. Их отключение сохраняет спокойное движение.

Canvas2D fallback использует те же ассеты, но более простое искажение. Сравнивайте основной эффект в WebGL; для проверки режима смотрите `snapshot().renderer.mode`.

Начальные пары цветов: золото `#fdab1b / #fdab1b`, лаванда `#8569d7 / #5e82d6`, серый `#777777 / #777777`, голубой `#00bbff / #00bbff`. Завершение использует `#0d0d0d`. Цвета каждой палитры сохраняются отдельно в текущей сессии; после перезагрузки восстановятся исходные.

`prefers-reduced-motion` включает паузу по умолчанию. Пользователь может продолжить анимацию. Пауза останавливает визуальные часы, Glow и кольца; таймер звонка и анализ звука продолжаются. Переключение состояния или цвета при паузе может перерисовать кадр.

## 6. Голос: не менять разницу громкостей

Последняя принятая настройка: тихая речь слегка оживляет фон; обычная даёт заметный отклик; громкая усиливает его. Долгая тихая фраза **не получает автоматическое усиление**.

В app.js цепочка: `MediaStream → highpass 80 Hz → lowpass 6000 Hz → AnalyserNode (fftSize=1024)`. RMS рассчитывается после удаления постоянной составляющей. В анализатор не подключён вывод на колонки.

Запрос: `echoCancellation:true`, `noiseSuppression:true`, `autoGainControl:false`. Фактическая поддержка ограничений зависит от браузера и устройства; при интеграции можно проверить `track.getSettings()`.

В audio-model.js:

```text
reference = 0.012                 // фиксированная опорная громкость
noise = 0.0001                   // исходная оценка шума
gate = max(0.0004, (noise * 2.5 + 0.0001) / sqrt(sensitivity))
target = 1 - exp(-max(0, RMS - gate) / 0.012 * 1.1 * sensitivity)
```

Адаптируется только шумовой порог во время тихого входа. Чтобы открыть реакцию, сигнал должен быть выше порога 35 мс. Удержание внутри фразы — 140 мс; 20-миллисекундные щелчки не открывают реакцию.

Два сглаживания `smoothEnvelope()`:

- Фраза: attack 75 мс, release 550 мс (`state.level`).
- Слоги: attack 40 мс, release 140 мс (`state.syllable`).

`voiceResponse()` объединяет их, применяет выразительность и независимые флаги. Полученный сигнал ускоряет разные часы лучей и градиента и усиливает их деформацию. Glow использует те же огибающие.

Демо использует **ту же модель громкости**, а не отдельный визуальный эффект. В нём тихая/обычная/громкая речь имеют базовый RMS 0.0015 / 0.009 / 0.035 и фразы с паузами. Есть тишина, шум и щелчки. Шаг расчёта демо ≤4 мс сохраняет отсечение коротких щелчков при низком FPS. Демо не воспроизводит звук.

`stopAudio()` останавливает tracks, отключает узлы и закрывает AudioContext, включая ожидающий контекст. Счётчик запроса отменяет поздно выданное разрешение. Выключение, завершение, повтор, смена пресета, уход со страницы и скрытие вкладки освобождают физический микрофон. Визуальные огибающие мягко затухают.

## 7. Кнопки, Glow и начало

Белый круг, иконка и hit target микрофона неподвижны при голосе. `glow-complete.png` — прямой экспорт Figma-группы 3524:2891; его исходные градиенты и размытие уже включены. `animateGlow()` меняет только внешний Halo. В тишине он небольшого размера, мягко дышит и переливается; при речи вокруг расходятся две волны. При mute активный Glow исчезает.

Нажатия разделены на `.button-face` и `.button-icon`. WAAPI слегка сжимает фон до 0.97 за 130 мс и возвращает через 1.008 к 1 за 340 мс. Центр иконки и геометрия кнопки сохраняются. Смена иконки — кроссфейд 240/280 мс, без изменения позиции. Не добавляйте конкурирующий `transform` всей кнопке: он возвращает уже исправленное смещение и дрожание.

Три кольца подготовки используют оригинальный `preparation-ring.png`, цикл **2 секунды**, последовательное мягкое подсвечивание, масштаб до 1.06 и подъём 1.25 px. За четыре секунды соединения проходят два цикла. В пресете подготовки кольца зациклены до ручного переключения.

Демовидео появляется через opacity за 400 мс при стабильной геометрии. Таймер общий для всех состояний: Gerbera Medium 13 px, фиксированная строка 34×12; pill 62×24, точка 8 px. Центрирование сохраняет принятый baseline. Для законченных уведомлений и фиксированных подписей использованы **целые оригинальные SVG**, плюс доступный DOM-текст. Это сохраняет точную форму букв и иконок.

## 8. Шрифты и адаптивность

Gerbera предоставлена заказчиком, все пять OTF включены локально: Light 300, Regular 400, Medium 500, Bold 700, Black 900. CSS использует общую семью и отдельные aliases для точного выбора начертаний. Заголовок звонка — Bold 17 px; таймер — Medium 13 px; подписи кнопок — Medium 14 px; сообщения в макете преимущественно Medium 15 px.

Эталонная ширина art — 402. ResizeObserver вычисляет масштаб по ширине телефона; высота артборда адаптируется, нижнее управление и свет остаются привязаны к низу. `overflow:clip` предотвращает сдвиг композиции при фокусе кнопки на низком экране. Проверяйте и ширину 360, и 402, и десктоп. Если SVG-подписи переводятся в обычный текст для локализации, сравните Gerbera и baseline с эталоном во всех состояниях.

## 9. Диагностический API

После загрузки ассетов доступны `window.callPrototype.configure(input)` и `snapshot()`. Они помогают разработчику проверить кадры; физический микрофон через них не запрашивается.

```js
// Обычная деморечь в активном кадре.
window.callPrototype.configure({
  scene: 'active', demo: 'normal', paused: false,
  raysVoice: true, gradientVoice: true, response: 1
});

// Только градиент реагирует на тихое демо.
window.callPrototype.configure({
  demo: 'quiet', raysVoice: false, gradientVoice: true
});

// Статический эталонный кадр без звука.
window.callPrototype.configure({scene: 'active', demo: 'off', static: true});

// Отдельные цвета выбранной палитры.
window.callPrototype.configure({palette: 'lavender', colors: ['#8569d7', '#5e82d6']});

// Снова настоящий флоу, включая 4 секунды подготовки.
window.callPrototype.configure({scene: 'flow', paused: false});
```

`configure()` возвращает снимок и валидирует диапазоны. `snapshot()` содержит `call`, `effect`, голосовые значения, уровень шума, часы, время звонка, режим renderer, top маски и состояние tracks. Он не возвращает аудиозапись. При `static:true` часы и визуальные огибающие сбрасываются, пауза включается. Для проверки голоса отключите static-паузу и включите demo: иначе можно видеть активный значок без анимации.

При наличии WebMCP зарегистрирован `configure_call_prototype` с теми же опциями. Это необязательный инструмент QA, без него сайт полностью работает.

## 10. Как перенести в реальный продукт

Рекомендуемая последовательность:

1. Сохранить этот commit в новой ветке как визуальный эталон. В продуктовой ветке перенести оригинальные ассеты, шрифты, CSS и модуль рендеринга. Сначала сравнить статические сцены.
2. Заменить демотаймер соединения реальными событиями транспорта. `connected()` вызывается при подтверждённом соединении, а не по задержке. Таймер начинается от этого события.
3. Управлять `peerMic` и `peerCamera` по событиям удалённого участника; убрать `joinPeer()` как демосимуляцию. Собственный mute не должен менять удалённый микрофон.
4. Подключить настоящие видеопотоки вместо фотографий, сохранив контейнеры, crop, размеры и переходы. Кнопка динамика сейчас меняет UI; реальную аудиомаршрутизацию реализовать отдельно.
5. Подать в сохранённую модель RMS локального потока после фильтров. Не создавать второй `getUserMedia` без необходимости; одна общая цепочка должна соответствовать состоянию mute. В реальном звонке заранее определить, означает mute отключение отправки или освобождение устройства, и согласовать это с индикатором.
6. Оставить `microphoneTarget`, фиксированную reference, огибающие и выключенное автоусиление без изменений до сравнения с заказчиком. Сначала сохранить разницу громкостей, затем калибровать чувствительность конкретных устройств.
7. Подключить завершение и повтор к реальному жизненному циклу звонка, закрыть все принадлежащие экрану ресурсы. Уход в фон сейчас освобождает микрофон; для фонового реального звонка это поведение нужно отдельно согласовать.
8. Проверить визуальную матрицу и физический микрофон по docs/ACCEPTANCE.md. Разрабатывать и публиковать на отдельном адресе; эталонный Site не обновлять.

Нет готового signaling-сервера, STUN/TURN, WebRTC или захвата камеры. Это граница текущего прототипа, а не скрытая функция. Не отправляйте звук на сервер ради визуальной реакции: она уже работает локально.

## 11. Если что-то не запускается

Пустой фон: проверьте HTTP-статусы ассетов, console и запуск через сервер. При переносе в подпапку сохраните относительные пути внутри `dist/`.

Микрофон не включается: HTTPS/localhost, разрешение сайта, выбранное устройство. Если доступ закрыт или устройства нет, UI предлагает демо. На телефоне откройте HTTPS-размещение: `127.0.0.1` компьютера не является адресом телефона.

Анимация стоит: проверьте паузу и системный reduced motion. Слабое искажение: `snapshot().renderer.mode==='canvas2d'` означает fallback. Слишком сильная реакция: верните sensitivity=1 и response=1; не включайте автоусиление.

Порт занят: остановите свой предыдущий сервер или используйте другой статический сервер для `dist/`. Исходный server.cjs намеренно сохранён неизменным, включая порт 4174.
